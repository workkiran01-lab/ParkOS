Five question columns describe the final check, not its former defect. “No (paired positive)” means the negative probe has a concrete positive witness in the same verifier; it is not an empty-table inference. Clock dependence is stated even when fixtures and PostgreSQL transaction time make it stable.

The runtime evidence and every deliberate-regression case are listed in [the run report](remaining-defects-report.md). The tests do not simulate Stripe outages or browser closure; IP3/FP2 are limited state assertions. Static body inspection is explicitly separate from behavioral verification.
